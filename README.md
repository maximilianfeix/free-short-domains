## Files

| Path | Content |
|---|---|
| `csv/all.csv` | every 1–3 character domain with a current RDAP answer "not registered", on all TLDs |
| `csv/<tld>.csv` | 1–3 character names with status `available` (not registered), `dropping` (redemption / pending delete), `unverified` (no current RDAP answer) or `unknown` (no DNS answer) |
| `txt/<tld>.txt` | RDAP-verified (not registered) 1–3 character domains, one per line |
| `four-letter/<tld>.txt` | 4-letter names (a–z) not in the zone, one per line (DNS check only) |
| `snapshot.json` | manifest of the shortfree snapshot these files come from: checksums, counts, coverage, source run |

CSV columns: `domain,tld,length,kind,status,first_seen,checked_at,verification,evidence_age_days` (`kind` = letters, digits or mixed; `verification` = rdap_verified, stale or pending; dates in UTC).

## Method

The lists come from [shortfree](https://github.com/maximilianfeix/shortfree), which queries every candidate name directly at the TLD's authoritative name servers and confirms each 1–3 character name in the registry's RDAP service (`404` = not registered; answers older than 14 days are not listed as verified). 4-letter names are DNS-checked only. Not registered does not mean registrable: registries reserve some names or sell them at premium prices, which RDAP does not show, so check at your registrar. Only ASCII names are covered (no IDN). A name can be taken minutes after the scan. Every update installs one complete, checksum-verified snapshot. Details: [accuracy](https://github.com/maximilianfeix/shortfree/blob/main/docs/accuracy.md). Also available as a [JSON/CSV API](https://github.com/maximilianfeix/shortfree/blob/main/docs/api.md).

If these lists save you time, a star helps other people find them.
